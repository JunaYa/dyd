## F1.1 设置修复（2026-09-20）

- 仅在 `screenshot_path` 缺失时写入默认目录，保留 `{ "value": ... }` 格式和空字符串代表默认目录的行为。
- `first_run.value = true` 表示启动引导已展示，false/null 表示需要展示。没有标记但已有有效目录的旧安装直接进入主白板；新安装展示启动窗口。标记记录窗口展示，不代表用户完成权限授权。
- 窗口显示前保存待展示标记；成功返回后保存已展示标记。独立引导界面及权限流程属于 F1.2。
- 已有 JSON 读取失败或字段类型错误时终止初始化，保留原文件，不将默认设置写回损坏文件。
- 自启以系统现有状态为准，启动只查询、不启用或禁用；移除无用途的启动参数。状态查询失败记录警告，不阻止白板启动。
- 截图目录字段无效时返回错误，避免 `unwrap` 崩溃。

验证：`settings.rs` 的 5 个 Rust 单元测试通过，覆盖新安装、旧安装、空目录、未完成引导、重启及错误类型；Oxlint、Oxfmt 检查通过。

本机仅约 830 MiB 可用空间，本轮通过临时最小 Cargo 包直接引用生产 `settings.rs`，使用相同 `serde_json = 1.0.151` 离线运行测试，未编译 Tauri 依赖。正常环境可用 `cargo test --manifest-path src-tauri/Cargo.toml settings::tests` 重现。此次修改的完整 Rust 编译、原生启动、跨重启持久化与系统自启开关回归尚未验证，F1.1 保留待验收状态。


## F1.2 窗口内容分离（2026-09-21）

| 窗口 | 路径 | 本项行为 |
| --- | --- | --- |
| main | `/` | 保留 Excalidraw，菜单、图形库、文件导入导出不变；原示例按钮改为窗口导航 |
| setting | `/setting` | 读取已有截图目录，展示快捷键及读取失败状态；不写入设置 |
| startup | `/startup` | 使用说明、快捷键、屏幕录制权限说明；开始使用会显示原白板并隐藏引导 |
| editor | `/editor` | 独立窗口与导航；明确说明图片加载尚未接通，不将编辑能力计为完成 |
| history | `/history` | 独立窗口与导航；说明历史尚未接通，不将未加载误报为没有文件 |
| preview | `/preview` | 不再加载第二份白板，实际截图查看留给 F1.6/F1.7 |

窗口由 Rust 按固定名称创建或复用，不接受任意 URL；导航不会关闭、重建或重载主白板。设置窗口取消配置文件中的预创建，统一经窗口工厂创建，关闭后重开仍使用相同路径。编辑器与历史的 capability 仅启用 `core:default`，不继承旧窗口的 store/shell 权限。

浏览器回归：设置、引导、编辑器、历史页分别加载成功；设置页在无原生环境时明确提示；主白板绘制矩形后点击设置入口，原画布图形与撤销按钮仍保留。新页面采用实色背景、可见焦点与至少 44px 点击区域，白板仍保持透明背景。

验证：`pnpm lint`、`pnpm fmt:check`、`pnpm build`、`cargo check --locked` 通过。Rust 输出包含既有弃用/未使用代码警告。图片读取、编辑、历史列表、授权操作不属于本项已实现功能。


原生验证：Apple Silicon macOS 上 `cargo build --locked` 与 `pnpm tauri bundle --debug --bundles app --no-sign` 成功，启动生成的 DYD.app 后实际完成以下回归：

- 设置窗口读取保存目录；从系统 Settings 菜单打开已存在窗口；关闭后再次打开，仍加载设置页。

- 编辑器与历史窗口在独立 capability 下可正常调用窗口导航。
- Cmd+Q 正常退出测试应用。
