## F1.1 设置修复（2026-09-20）

- 仅在 `screenshot_path` 缺失时写入默认目录，保留 `{ "value": ... }` 格式和空字符串代表默认目录的行为。
- `first_run.value = true` 表示启动引导已展示，false/null 表示需要展示。没有标记但已有有效目录的旧安装直接进入主白板；新安装展示启动窗口。标记记录窗口展示，不代表用户完成权限授权。
- 窗口显示前保存待展示标记；成功返回后保存已展示标记。独立引导界面及权限流程属于 F1.2。
- 已有 JSON 读取失败或字段类型错误时终止初始化，保留原文件，不将默认设置写回损坏文件。
- 自启以系统现有状态为准，启动只查询、不启用或禁用；移除无用途的启动参数。状态查询失败记录警告，不阻止白板启动。
- 截图目录字段无效时返回错误，避免 `unwrap` 崩溃。

验证：`settings.rs` 的 5 个 Rust 单元测试通过，覆盖新安装、旧安装、空目录、未完成引导、重启及错误类型；Oxlint、Oxfmt 检查通过。
